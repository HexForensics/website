# SEO Configuration Guide

This document outlines the Search Engine Optimization (SEO) implementation for the Hex Forensics website.

## Overview

The website implements comprehensive SEO best practices to maximize search engine visibility while maintaining security against web scrapers.

## Meta Tags Configuration

### Dynamic Meta Tags

Meta tags are dynamically generated per page in [app/Controllers/Home.php](../../app/Controllers/Home.php):

```php
protected array $seoData = [
    'home' => [
        'title'       => 'Home',
        'description' => 'Hex Forensics provides expert digital forensics...',
        'keywords'    => 'digital forensics, cyber security...',
    ],
    // ... more pages
];
```

### Implementation in Header

Located in [app/Views/layout/header.php](../../app/Views/layout/header.php):

| Meta Tag | Implementation |
|----------|----------------|
| `<title>` | `<?= $page_title; ?> - Hex Forensics` |

| `keywords` | Dynamic from controller or default fallback |
| `robots` | `index, follow` (default) |
| `author` | `Hex Forensics` |
| `canonical` | Current URL via `current_url()` |

## Open Graph Protocol

Open Graph tags enable rich previews when shared on social platforms.

### Implementation

```html
<meta property="og:type" content="website">
<meta property="og:url" content="<?= current_url(); ?>">
<meta property="og:title" content="<?= $page_title; ?> - Hex Forensics">
<meta property="og:description" content="...">
<meta property="og:image" content="<?= base_url('assets/logo/og-image.png'); ?>">
<meta property="og:site_name" content="Hex Forensics">
<meta property="og:locale" content="en_NG">
```

### Required Asset

Create an Open Graph image at: `public/assets/logo/og-image.png`
- **Recommended size:** 1200 x 630 pixels
- **Format:** PNG or JPG
- **Content:** Logo, tagline, brand colors

    "url": "https://hexforensics.com",

        "@type": "ContactPoint",

## XML Sitemap

### Dynamic Sitemap

Generated by [app/Controllers/Sitemap.php](../../app/Controllers/Sitemap.php)

**URL:** `https://hexforensics.com/sitemap.xml`

### Sitemap Structure

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://hexforensics.com/</loc>
    <lastmod>2026-01-22</lastmod>
    <changefreq>weekly</changefreq>
    <priority>1.0</priority>
  </url>
  <!-- ... more URLs -->
</urlset>
```

### Pages Included

| URL | Priority | Change Frequency |
|-----|----------|------------------|
| `/` | 1.0 | weekly |
| `/about-us` | 0.9 | monthly |
| `/services` | 0.9 | monthly |
| `/partners` | 0.8 | monthly |
| `/contact` | 0.8 | monthly |
| `/services/digital-forensics` | 0.8 | monthly |
| `/services/cyber-security` | 0.8 | monthly |
| `/services/fraud-investigation` | 0.8 | monthly |
| `/services/intelligence` | 0.8 | monthly |
| `/services/training-and-education` | 0.8 | monthly |

### Adding New Pages

Edit the `$pages` array in [Sitemap.php](../../app/Controllers/Sitemap.php):

```php
protected array $pages = [
    [
        'loc'        => 'new-page',
        'priority'   => '0.7',
        'changefreq' => 'monthly',
    ],
];
```

## Canonical URLs

### Purpose

Prevents duplicate content issues by specifying the preferred URL for each page.

### Implementation

```html
<link rel="canonical" href="<?= isset($canonical_url) ? $canonical_url : current_url(); ?>">
```

### Automatic Generation

The `current_url()` function generates canonical URLs automatically. For custom canonicals, pass `canonical_url` in the controller:

```php
$data['canonical_url'] = base_url('services');
```

|--------|----------------|

## Search Console Setup

### Google Search Console

1. Go to [Google Search Console](https://search.google.com/search-console)
2. Add property: `https://hexforensics.com`
3. Verify via DNS TXT record or HTML file
4. Submit sitemap: `https://hexforensics.com/sitemap.xml`

### Bing Webmaster Tools

1. Go to [Bing Webmaster Tools](https://www.bing.com/webmasters)
2. Import from Google Search Console or add manually
3. Submit sitemap
